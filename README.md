# Control Flow Graph Generator

## Project Overview

This project implements a Python-based Control Flow Graph (CFG) generator for a supported subset of C++ and Java function syntax.

The program analyzes a function, constructs its control flow graph, reduces unnecessary nodes through basic-block optimization, validates the resulting graph, calculates cyclomatic complexity, and generates a PNG visualization using Graphviz.

## Features

- Lexical analysis of C++/Java-like source code
- Recursive-descent parsing
- CFG construction with nested control structures
- Basic-block optimization
- Short-circuit evaluation of Boolean conditions
- CFG validation
- Cyclomatic complexity calculation
- PNG graph visualization
- Command-line interface
- Error handling for invalid input

### Supported Statements

- Assignment and arithmetic statements
- Simple and compound Boolean expressions (`&&`, `||`)
- `if` and `if-else`
- `while` loops
- `for` loops
- `do-while` loops
- Read and write statements represented as ordinary function-call statements
- Comments
- `return`
- `break`
- `continue`
- Increment and decrement expressions

## Requirements

- Python 3
- Python `graphviz` package
- Graphviz software, including the `dot` executable

Install the Python package:

```powershell
pip install graphviz
```

Graphviz must also be installed separately, and its `bin` directory must be accessible through the system PATH.

Verify installation:

```powershell
dot -V
```

## Usage

Generate a CFG:

```powershell
python main.py examples\partial_return.cpp
```

Specify a different output filename:

```powershell
python main.py examples\partial_return.cpp -o partial_return_cfg
```

Disable optimization:

```powershell
python main.py examples\partial_return.cpp --no-optimize
```

Display command-line options:

```powershell
python main.py --help
```

## CFG Construction

The program processes source code through the following stages:

1. **Lexical Analysis:** Converts source code into tokens.
2. **Parsing:** Constructs an abstract syntax tree (AST).
3. **CFG Construction:** Creates graph nodes and directed edges representing execution paths.
4. **Optimization:** Removes unnecessary entry nodes and merges sequential statements into basic blocks where possible.
5. **Validation:** Checks graph structure and connectivity.
6. **Complexity Calculation:** Computes cyclomatic complexity.
7. **Visualization:** Generates a directed graph using Graphviz.

### Cyclomatic Complexity

For the connected CFGs generated by the program, cyclomatic complexity is calculated using:

\[
V(G) = E - N + 2
\]

Where:

- \(E\) = number of directed edges
- \(N\) = number of vertices

## Testing

The project includes automated unit tests.

Run the test suite:

```powershell
python -m unittest test_cfg -v
```

The current regression suite contains 23 passing tests covering control structures, Boolean expressions, nesting, loop control, CFG validation, optimization-related behavior, and cyclomatic complexity.

## Error Handling

The command-line interface reports errors for missing source files, malformed source code detected by the parser, CFG validation failures, and selected visualization or file-system failures.

An unsuccessful run returns a nonzero exit code.

## Limitations

- The parser supports a subset of C++ and Java syntax rather than the complete language specifications.
- The command-line interface expects a source file containing one supported function.
- Advanced language constructs such as classes, templates, and full preprocessor handling are outside the current implementation.
- Graph generation requires Graphviz to be installed.
- Some uncommon control-flow patterns may require additional parser or CFG validation support.
